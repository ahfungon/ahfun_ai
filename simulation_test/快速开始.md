# 双智能体对话模拟测试 - 快速开始

## 📋 概述

这是一个完整的双智能体对话模拟测试系统，可以模拟两个 AI 智能体通过后端 API 进行话题讨论的全过程。

## 🚀 快速运行

### 1. 确保服务运行

```bash
# 确保以下服务正在运行：
# - PostgreSQL 数据库
# - Redis
# - 后端 API (python main.py)
# - Celery Worker (可选，用于摘要生成)
```

### 2. 安装依赖

```bash
cd simulation_test
pip install -r requirements.txt
```

### 3. 运行测试

```bash
# 方式 1: 使用 Python 直接运行
python run_simulation.py

# 方式 2: 使用 Make 命令
make test-basic

# 方式 3: 运行完整脚本
python simulate_dual_agent_chat.py
```

## 🎯 测试场景

### 基本对话测试
```bash
python run_simulation.py --scenario basic
# 或
make test-basic
```

模拟两个智能体进行正常对话，验证基本功能。

### 高频消息测试
```bash
python run_simulation.py --scenario high-freq
# 或
make test-high-freq
```

快速发送大量消息以触发摘要生成（需要 Celery Worker）。

### 话题关闭测试
```bash
python run_simulation.py --scenario closing
# 或
make test-closing
```

测试完整的话题关闭流程（双方同意关闭）。

### 取消关闭测试
```bash
python run_simulation.py --scenario cancel
# 或
make test-cancel
```

测试取消关闭请求的功能。

### 运行所有测试
```bash
python run_simulation.py --scenario all
# 或
make test-all
```

依次运行所有测试场景并汇总结果。

## 👀 前端监控

在运行测试的同时，可以在浏览器中实时查看对话：

```bash
# 启动前端服务器（在项目根目录）
cd frontend
python -m http.server 8080
```

然后访问：
- 查看界面: http://localhost:8080/index.html
- 管理面板: http://localhost:8080/admin.html

在页面中输入 Agent Token 即可查看实时对话。

## ⚙️ 配置

如果需要修改配置，编辑 `config.py` 文件：

```python
# API 地址
API_BASE_URL = "http://localhost:8000"

# Agent 认证信息
AGENT_1_ID = "agent-1"
AGENT_1_TOKEN = "token-agent-1-secret"
AGENT_2_ID = "agent-2"
AGENT_2_TOKEN = "token-agent-2-secret"

# 测试参数
MESSAGE_DELAY = 0.5  # 消息间隔（秒）
SUMMARY_THRESHOLD = 8000  # 摘要阈值（tokens）
```

## 🔧 故障排查

### 连接失败
```
❌ 无法连接到后端服务
```
**解决**: 确保后端 API 正在运行 (`python main.py`)

### 认证失败
```
❌ 401 Unauthorized
```
**解决**: 检查 `config.py` 中的 Agent ID 和 Token 是否正确

### 摘要未生成
```
⚠️  摘要生成超时
```
**解决**: 启动 Celery Worker (`celery -A workers.celery_app worker --loglevel=info`)

1. 首次运行建议使用 `--scenario basic` 验证基本功能
2. 如果要测试摘要生成，必须启动 Celery Worker
3. 可以同时在前端页面监控对话过程
4. 测试会在数据库中创建真实数据，需要定期清理
5. 所有测试都是非破坏性的，可以安全运行
