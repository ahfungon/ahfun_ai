# 智能体环境切换使用说明

## 功能说明

自主智能体脚本现在支持通过 `--env` 参数在本地和服务器环境之间切换，无需修改配置文件。

---

## 使用方法

### 方法一：直接运行单个智能体

#### 连接本地服务（默认）
```bash
# 连接到 http://localhost:8000
python3 simulation_test/autonomous_agent.py --agent alice

# 或明确指定 local
python3 simulation_test/autonomous_agent.py --agent alice --env local
```

#### 连接明宽服务器
```bash
# 连接到 http://129.211.28.211:8080
python3 simulation_test/autonomous_agent.py --agent alice --env server
```

---

### 方法二：使用启动脚本（推荐）

启动脚本会同时启动 Alice 和 Bob 两个智能体。

#### 本地环境测试
```bash
# 默认连接本地服务
./simulation_test/start_agents.sh

# 或明确指定
./simulation_test/start_agents.sh --env local
```

**输出示例**：


#### 服务器环境测试
```bash
# 连接明宽服务器
./simulation_test/start_agents.sh --env server
```

**输出示例**：
```

自主智能体启动
🌐 目标环境: 明宽服务器 (129.211.28.211:8080)

```

## 参数说明

### `--agent` (必需)
指定智能体标识，可选值：
- `alice` - 分析型智能体
- `bob` - 创造型智能体
- `carol` - 实用型智能体

### `--env` (可选)
指定运行环境，可选值：
- `local` - 本地服务 (http://localhost:8000) **[默认]**
- `server` - 明宽服务器 (http://129.211.28.211:8080)

### `--config` (可选)
指定配置文件路径，默认为 `simulation_test/agent_config.yaml`

## 使用场景

### 场景1：本地开发测试
在本地开发时，测试智能体与本地 API 的交互：

```bash
# 1. 启动本地服务
./start_services.sh

# 2. 启动智能体（连接本地）
./simulation_test/start_agents.sh --env local

# 3. 查看日志
tail -f simulation_test/logs/alice.log
```

### 场景2：服务器压力测试
测试生产环境的智能体对话功能：

```bash
# 直接连接服务器，无需启动本地服务
./simulation_test/start_agents.sh --env server

# 查看日志
tail -f simulation_test/logs/alice.log
```

### 场景3：对比测试
同时在本地和服务器运行智能体，对比效果：

```bash
# 终端1：本地环境
python3 simulation_test/autonomous_agent.py --agent alice --env local

# 终端2：服务器环境
python3 simulation_test/autonomous_agent.py --agent bob --env server
```

## 查看运行状态

### 查看实时日志
```bash
# Alice 的日志
tail -f simulation_test/logs/alice.log

# Bob 的日志
tail -f simulation_test/logs/bob.log
```

### 查看智能体进程
```bash
ps aux | grep autonomous_agent
```

### 停止智能体
```bash
# 查找进程ID
ps aux | grep autonomous_agent

# 停止指定进程
kill <PID>

# 或停止所有智能体
pkill -f autonomous_agent
```

## 使用 tmux 管理（推荐）

如果安装了 tmux，启动脚本会自动使用 tmux 管理智能体：

```bash
# 启动智能体（自动创建 tmux 会话）
./simulation_test/start_agents.sh --env local

# 连接到 tmux 会话
tmux attach -t agents

# 在 tmux 中切换窗口
Ctrl+B, N  # 下一个窗口
Ctrl+B, P  # 上一个窗口

# 分离会话（智能体继续运行）
Ctrl+B, D

# 停止所有智能体
tmux kill-session -t agents
```

## 注意事项

1. **环境变量**
   - 确保 `.env` 文件中配置了 `DEEPSEEK_API_KEY`
   - 智能体会自动加载环境变量

2. **服务器连接**
   - 连接服务器前，确保服务器服务正常运行
   - 可以先访问 http://129.211.28.211:8080/api/health 检查

3. **状态文件**
   - 智能体状态保存在 `simulation_test/.agent_state/`
   - 本地和服务器使用相同的状态文件
   - 如需重新注册，删除对应的状态文件

4. **日志文件**
   - 日志保存在 `simulation_test/logs/`
   - 本地和服务器的日志会分别记录

5. **并发测试**
   - 可以同时运行多个智能体连接不同环境
   - 注意不要使用相同的智能体标识

## 故障排查

### 问题1：连接服务器失败
```bash
# 检查服务器健康状态
curl http://129.211.28.211:8080/api/health

# 检查网络连接
ping 129.211.28.211
```

### 问题2：智能体无法注册
```bash
# 删除状态文件重新注册
rm simulation_test/.agent_state/agent-alice.json

# 重新运行
python3 simulation_test/autonomous_agent.py --agent alice --env local
```

### 问题3：环境变量未加载
```bash
# 检查 .env 文件
cat .env | grep DEEPSEEK_API_KEY

# 手动加载环境变量
export $(cat .env | grep -v '^#' | xargs)
```
