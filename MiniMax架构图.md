## 🔄 数据流图

### 1. 前端模拟器调用 MiniMax

```
┌──────────────┐
│ 前端模拟器    │
│ (浏览器)     │
└──────┬───────┘
       │ 1. POST /api/admin/llm/proxy
       │    { provider: "minimax", messages: [...] }
       ▼
┌──────────────┐
│ LLM 代理端点 │
│ (后端)       │
└──────┬───────┘
       │ 2. 读取系统配置
       │    - minimax_api_key
       │    - minimax_api_url
       │    - minimax_model
       ▼
┌──────────────┐
│ MiniMax API  │
│ (外部)       │
└──────┬───────┘
       │ 3. 返回响应
       │    { choices: [{ message: { content: "..." } }] }
       ▼
┌──────────────┐
│ 过滤思考标签  │
│ (后端)       │
└──────┬───────┘
       │ 4. 返回过滤后的内容
       │    { success: true, content: "..." }
       ▼
┌──────────────┐
│ 显示回复     │
│ (前端)       │
└──────────────┘
```

## 🛡️ 思考标签过滤机制

```
┌──────────────────────────────────────────────────────────┐
│              MiniMax API 响应                             │
│  "你好！<think>我需要思考一下...</think>很高兴认识你！"     │
└──────────────┬───────────────────────────────────────────┘
               │
               ▼
┌──────────────────────────────────────────────────────────┐
│              后端过滤 (主要)                              │
│  re.sub(r'<think>[\s\S]*?</think>', '', content)        │
└──────────────┬───────────────────────────────────────────┘
               │
               ▼
┌──────────────────────────────────────────────────────────┐
│              过滤后内容                                   │
│  "你好！很高兴认识你！"                                   │
└──────────────┬───────────────────────────────────────────┘
               │
               ▼
┌──────────────────────────────────────────────────────────┐
│              返回给前端                                   │
│  { success: true, content: "你好！很高兴认识你！" }       │
└──────────────┬───────────────────────────────────────────┘
               │
               ▼
┌──────────────────────────────────────────────────────────┐
│              前端过滤 (备用)                              │
│  reply.replace(/<think>[\s\S]*?<\/think>/gi, '')        │
└──────────────┬───────────────────────────────────────────┘
               │
               ▼
┌──────────────────────────────────────────────────────────┐
│              显示给用户                                   │
│  "你好！很高兴认识你！"                                   │
└──────────────────────────────────────────────────────────┘
```

## 🔄 Worker 重启流程

```
┌──────────────┐
│ 用户修改配置  │
│ (系统配置页面)│
└──────┬───────┘
       │ 1. 保存配置到数据库
       ▼
┌──────────────┐
│ 点击重启按钮  │
└──────┬───────┘
       │ 2. POST /api/admin/worker/restart
       ▼
┌──────────────┐
│ 执行重启脚本  │
│ restart_     │
│ worker_      │
│ quick.sh     │
└──────┬───────┘
       │ 3. pkill -f "celery.*worker"
       ▼
┌──────────────┐
│ 停止旧 Worker│
└──────┬───────┘
       │ 4. 等待 1 秒
       ▼
┌──────────────┐
│ 启动新 Worker│
│ celery -A    │
│ workers.     │
│ celery_app   │
│ worker       │
└──────┬───────┘
       │ 5. Worker 启动
       ▼
┌──────────────┐
│ 读取新配置   │
│ - llm_       │
│   provider_  │
│   scoring    │
│ - llm_       │
│   provider_  │
│   summary    │
└──────┬───────┘
       │ 6. 初始化 LLM 客户端
       ▼
┌──────────────┐
│ Worker 就绪  │
│ 使用新配置   │
└──────────────┘
```

## 📊 组件关系图

```
┌─────────────────────────────────────────────────────────┐
│                    核心组件                              │
└─────────────────────────────────────────────────────────┘

SystemConfigService (系统配置服务)
    │
    ├─► MessageScoringService (消息评分服务)
    │       │
    │       └─► MiniMaxClient / DeepSeekClient
    │
    ├─► SummaryService (对话总结服务)
    │       │
    │       └─► MiniMaxClient / DeepSeekClient
    │
    └─► LLM Proxy Endpoint (代理端点)
            │
            └─► MiniMaxClient / DeepSeekClient

┌─────────────────────────────────────────────────────────┐
│                    数据模型                              │
└─────────────────────────────────────────────────────────┘

SystemConfig (系统配置)
    ├─ key: llm_provider_scoring
    ├─ key: llm_provider_summary
    ├─ key: minimax_api_key
    ├─ key: minimax_api_url
    └─ key: minimax_model

Topic (话题)
    ├─ summary (总结)
    ├─ llm_suggestion (LLM 建议)
    └─ end_score (结束评分)

Message (消息)
    └─► MessageRelevanceScore (相关性评分)
            ├─ relevance_score (评分)
            └─ evaluation_comment (评价)

SummaryHistory (总结历史)
    ├─ summary (总结)
    ├─ llm_suggestion (建议)
    └─ end_score (评分)
```

## 🎯 关键路径

### 路径 1: 前端模拟器 → MiniMax API
```
前端 → 代理端点 → 系统配置 → MiniMax Client → MiniMax API → 过滤 → 前端
```

### 路径 2: 消息评分 → MiniMax API
```
消息 → Worker → 评分服务 → 系统配置 → MiniMax Client → MiniMax API → 数据库
```

### 路径 3: 对话总结 → MiniMax API
```
Token阈值 → Worker → 总结服务 → 系统配置 → MiniMax Client → MiniMax API → 数据库
```
