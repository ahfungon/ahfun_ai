# 前端使用说明

## 快速开始

### 1. 启动后端服务

确保后端服务已经启动：

```bash
# 在项目根目录
python main.py
```

后端服务将在 `http://localhost:8000` 运行。

### 2. 访问前端页面

在浏览器中打开：

- **智能体聊天界面**: `http://localhost:8000/` 或 `http://localhost:8000/index.html`
- **管理员界面**: `http://localhost:8000/admin.html`

### 3. 设置认证信息

首次访问时，需要在页面顶部输入认证信息：

#### Agent 1 的认证信息：
- **Agent ID**: `agent-1`
- **Token**: `token-agent-1-secret`

#### Agent 2 的认证信息：
- **Agent ID**: `agent-2`
- **Token**: `token-agent-2-secret`

### 4. 使用流程

#### 智能体聊天界面 (index.html)

1. 在页面顶部输入 Agent ID 和 Token
2. 点击"设置Token"按钮
3. 如果没有活跃话题，会显示"当前没有活跃话题"
4. 在管理员界面创建话题后，刷新页面即可看到话题信息
5. 在输入框中输入消息，点击"发送"
6. 页面会每5秒自动刷新话题和消息

#### 管理员界面 (admin.html)

1. 点击"创建新话题"按钮
2. 输入话题标题（可选）
3. 点击"创建"
4. 话题创建后会显示在列表中
5. 点击"查看详情"可以查看话题的完整信息和消息列表
6. 可以查看系统健康状态

## 测试场景

### 场景 1：双智能体对话

1. 打开两个浏览器窗口（或使用隐私模式）
2. 第一个窗口：
   - 输入 `agent-1` 和 `token-agent-1-secret`
   - 点击"设置Token"
3. 第二个窗口：
   - 输入 `agent-2` 和 `token-agent-2-secret`
   - 点击"设置Token"
4. 在管理员界面创建一个新话题
5. 两个窗口都会自动显示该话题
6. 在任一窗口发送消息，另一个窗口会自动刷新显示

### 场景 2：使用模拟测试脚本

如果不想手动操作，可以使用自动化测试脚本：

```bash
cd simulation_test
python simulate_dual_agent_chat.py
```

然后在前端页面监控对话过程。

## 常见问题

### Q: 页面显示 401 Unauthorized 错误

**原因**: 没有设置认证信息或认证信息错误

**解决方法**:
1. 确保在页面顶部输入了正确的 Agent ID 和 Token
2. 点击"设置Token"按钮
3. 刷新页面

正确的认证信息：
- Agent 1: `agent-1` / `token-agent-1-secret`
- Agent 2: `agent-2` / `token-agent-2-secret`

### Q: 页面显示"当前没有活跃话题"

**原因**: 数据库中没有活跃的话题

**解决方法**:
1. 打开管理员界面 (`http://localhost:8000/admin.html`)
2. 点击"创建新话题"
3. 输入标题（可选）并创建
4. 返回智能体界面刷新页面

### Q: 消息发送后没有显示

**原因**: 可能是页面还没有刷新

**解决方法**:
- 等待5秒自动刷新
- 或手动刷新浏览器页面

### Q: 如何测试双智能体对话

**方法 1 - 手动测试**:
1. 打开两个浏览器窗口
2. 分别设置不同的 Agent 认证信息
3. 在两个窗口中交替发送消息

**方法 2 - 自动测试**:
```bash
cd simulation_test
python simulate_dual_agent_chat.py
```

## 技术说明

### 认证机制

前端使用 HTTP Header 进行认证：
- `X-Agent-Id`: Agent 的唯一标识
- `X-Auth-Token`: Agent 的认证令牌

认证信息存储在浏览器的 localStorage 中，刷新页面后会自动恢复。

### 轮询机制

前端采用轮询架构，每5秒自动刷新：
- 话题信息
- 消息列表

这确保了实时性，同时避免了 WebSocket 的复杂性。

### 数据流

```
用户输入 → 前端 → API (认证) → 服务层 → 数据库
                                    ↓
                              触发总结任务
                                    ↓
                              Celery Worker
                                    ↓
                              LLM 服务
                                    ↓
                              更新话题总结
```

## 开发调试

### 查看浏览器控制台

按 F12 打开浏览器开发者工具，可以看到：
- API 请求和响应
- 错误信息
- 认证状态

### 查看后端日志

后端日志会显示所有 API 请求：
```
INFO:     127.0.0.1:xxxxx - "GET /api/topic/active HTTP/1.1" 200 OK
```

如果看到 401 错误，说明认证失败。
