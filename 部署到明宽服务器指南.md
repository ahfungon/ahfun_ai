# 部署到明宽服务器指南

- **IP**: 129.211.28.211
- **用户**: ubuntu
- **SSH 密钥**: ~/.ssh/mingkuan.pem
- **部署目录**: ~/dual-agent-chat

## 快速部署

### 一键部署（推荐）

```bash

```

这个脚本会自动完成：
1. 导出本地数据库
2. 同步代码到服务器
3. 复制环境配置
4. 在服务器上安装依赖
5. 导入数据库
6. 重启所有服务
7. 验证部署

### 检查部署状态

```bash
./check_mingkuan_status.sh
```

## 手动部署步骤

### 1. 导出本地数据库

```bash
PGPASSWORD='dual_agent_pass' pg_dump -h localhost -U dual_agent_user -d dual_agent_chat \
    --clean --if-exists \
    -f dual_agent_chat_data.sql
```

### 2. 同步代码

```bash
rsync -avz --progress \
    --exclude 'venv' \
    --exclude '.git' \
    --exclude '__pycache__' \
    --exclude '.hypothesis' \
    --exclude '*.pyc' \
    --exclude '.pytest_cache' \
    --exclude 'logs' \
    --exclude '.env' \
    -e "ssh -i ~/.ssh/mingkuan.pem" \
    ./ ubuntu@129.211.28.211:~/dual-agent-chat/
```

### 3. 复制环境配置

```bash
scp -i ~/.ssh/mingkuan.pem .env ubuntu@129.211.28.211:~/dual-agent-chat/.env
```

### 4. 连接到服务器

```bash
ssh -i ~/.ssh/mingkuan.pem ubuntu@129.211.28.211
```

### 5. 在服务器上执行

```bash
cd ~/dual-agent-chat

# 激活虚拟环境
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 重建数据库
sudo -u postgres psql << 'EOSQL'
SELECT pg_terminate_backend(pid) FROM pg_stat_activity WHERE datname = 'dual_agent_chat' AND pid <> pg_backend_pid();
DROP DATABASE IF EXISTS dual_agent_chat;
DROP USER IF EXISTS dual_agent_user;
CREATE USER dual_agent_user WITH PASSWORD 'dual_agent_pass';
CREATE DATABASE dual_agent_chat OWNER dual_agent_user;
GRANT ALL PRIVILEGES ON DATABASE dual_agent_chat TO dual_agent_user;
EOSQL

# 导入数据
PGPASSWORD='dual_agent_pass' psql -h localhost -U dual_agent_user -d dual_agent_chat -f dual_agent_chat_data.sql

# 重启服务
sudo systemctl restart dual-agent-api
sudo systemctl restart dual-agent-celery
sudo systemctl restart dual-agent-celery-beat
sudo systemctl restart nginx
```

SELECT 
    t.id,
    t.title,
    t.status,
    t.created_at,
    COUNT(m.id) as message_count
FROM topics t
LEFT JOIN messages m ON t.id = m.topic_id
GROUP BY t.id
ORDER BY t.created_at DESC
LIMIT 10;

## 故障排查

### 服务无法启动

1. 检查日志：
```bash
ssh -i ~/.ssh/mingkuan.pem ubuntu@129.211.28.211 'journalctl -u dual-agent-api -n 50'
```

2. 检查端口占用：
```bash
ssh -i ~/.ssh/mingkuan.pem ubuntu@129.211.28.211 'sudo netstat -tlnp | grep 8000'
```

3. 检查虚拟环境：
```bash
ssh -i ~/.ssh/mingkuan.pem ubuntu@129.211.28.211 'source ~/dual-agent-chat/venv/bin/activate && python --version'
```

### 数据库连接失败

1. 检查 PostgreSQL 状态：
```bash
ssh -i ~/.ssh/mingkuan.pem ubuntu@129.211.28.211 'sudo systemctl status postgresql'
```

2. 测试数据库连接：
```bash
ssh -i ~/.ssh/mingkuan.pem ubuntu@129.211.28.211 'PGPASSWORD=dual_agent_pass psql -h localhost -U dual_agent_user -d dual_agent_chat -c "SELECT 1;"'
```

### Redis 连接失败

```bash
ssh -i ~/.ssh/mingkuan.pem ubuntu@129.211.28.211 'redis-cli ping'
```

如果失败，重启 Redis：
```bash
ssh -i ~/.ssh/mingkuan.pem ubuntu@129.211.28.211 'sudo systemctl restart redis-server'
```
